# Demographic Data Analyzer

This is a Python project that analyzes the Adult Census Income dataset using the Pandas library.

It was completed as part of the **freeCodeCamp Data Analysis with Python Certification**.

## Features

This project calculates:

- Number of people in each race
- Average age of men
- Percentage of people with a Bachelor's degree
- Percentage of people earning more than \$50K based on education level
- Minimum working hours per week
- Percentage of high-income earners among people who work the minimum hours
- Country with the highest percentage of high-income earners
- Most common high-income occupation in India

## Technologies Used

- Python
- Pandas

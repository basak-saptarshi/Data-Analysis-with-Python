# 🌊 Sea Level Predictor

A Python data analysis project that visualizes historical global sea level changes and predicts future sea level rise using linear regression.

This project is one of the certification projects from the **freeCodeCamp Data Analysis with Python** course.

---

## 📌 Project Overview

The program:

- Loads historical sea level data from a CSV file.
- Creates a scatter plot of the recorded sea levels.
- Fits a linear regression line using the entire dataset.
- Fits a second regression line using data from the year 2000 onward.
- Predicts sea level rise through the year 2050.
- Saves the generated visualization as an image.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/sea-level-predictor.git
```

Navigate to the project folder:

```bash
cd sea-level-predictor
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
python sea_level_predictor.py
```

The program will:

- Generate the visualization
- Save it as **sea_level_plot.png**
- Display the plot on the screen
